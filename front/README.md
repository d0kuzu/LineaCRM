# Linea CRM

Desktop-фронтенд на React, TypeScript и Vite по [английскому макету Work overview в Figma](https://www.figma.com/design/d1MoOsOybR0sMmANvrpEnc/Linea-CRM?node-id=4-75).

## Локальный запуск

Понадобится Node.js 20.19+ из ветки 20 или версия от 22.12. Для входа и работы с клиентами запустите PostgreSQL и сервисы `auth-service`, `crm-service` и `api-gateway`. [Запуск серверной части](../back/README.md#запуск)

Команды ниже выполняются из папки `front/`. Из корня проекта сначала выполните `cd front`.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Войдите или выберите **Create account**. Новый пользователь может создать пространство или передать ID аккаунта администратору команды. Для восстановления пароля форма **Forgot password?** принимает код, выданный оператором. После входа в пространство начальная страница — **Customers**. Участник нескольких команд может переключать пространство на верхней панели.

По умолчанию Vite проксирует запросы `/auth` и `/crm` на `http://127.0.0.1:8085`. Если gateway слушает другой адрес, задайте его в `front/.env.local`, например `LINEA_GATEWAY_URL=http://127.0.0.1:9085`, и перезапустите Vite. Эта настройка действует для `npm run dev` и `npm run preview`.

Для проверки типов и сборки выполните `npm run build`. При публикации отдавайте файлы из `front/dist/` по HTTPS. На том же домене направьте префиксы `/auth/` и `/crm/` на gateway, сохраняя путь, строку запроса, HTTP-метод и заголовок `Authorization`. Браузер использует относительные URL.

## Работа с клиентами

В **Customers** доступны вкладки контактов и компаний. Создайте компанию, откройте её карточку и добавьте контакт. Списки поддерживают поиск, фильтры по тегу, сегменту и ответственному, сортировку и переход по страницам. Контакты также можно отбирать по компании. В карточке видны прежние и новые значения изменённых полей. Сотрудник может добавить заметку или зафиксировать состоявшийся звонок, встречу либо письмо.

Менеджер продаж работает со своими карточками. Руководитель и администратор видят и редактируют все карточки пространства. Поддержка читает карточки и их историю. Администратор управляет участниками и ролями в окне команды.

Чтобы настроить поля, войдите как администратор, в **Customers** выберите **Companies** или **Contacts** и откройте **Manage fields**. Нажмите **Add text field**, введите название, при необходимости отметьте **Required** и сохраните поле. Через **Edit** можно переименовать собственное поле или изменить обязательность. Для стандартных полей доступна настройка обязательности, имя требуется всегда.

Настройки относятся к выбранному типу карточки в текущем пространстве. Старые карточки можно просматривать сразу. При следующем редактировании форма попросит заполнить новые обязательные поля. При переименовании значения сохраняются, а в истории остаётся название, которое поле носило в момент записи.

## Продажи

В **Sales → Leads** создайте лид с названием и описанием. Руководитель и администратор могут выбрать или сменить ответственного. В карточке открытого лида нажмите **Convert to deal**, при необходимости укажите компанию и контактных лиц. Сделку можно снова открыть из лида, из списка **Deals** или через общий поиск. Ссылки на компанию и контакты можно изменить и после конверсии. Карточки клиентов открываются с теми же правами, что и в Customers.

При конверсии можно указать сумму и валюту, плановую дату закрытия и вероятность от 0 до 100%. При вводе суммы форма предлагает KZT. Код валюты можно изменить. Позже параметры можно изменить или очистить в карточке сделки. Там же видны автор, время, прежние и новые значения. Пустые поля у старых сделок можно заполнить в любой момент. Менеджеру доступны свои сделки, руководителю и администратору — все сделки пространства. Сотрудник поддержки может читать карточки и историю.

## Данные и язык

Компании, контакты, лиды и сделки загружаются с сервера. В общем поиске отдельно помечены демонстрационные сделки и встречи. Макет воронки в Sales, обзор, задачи, календарь, аналитика и ассистент используют демонстрационные данные за 4 ноября 2026 года. Отметки выполнения демозадач сохраняются в браузере, история демодиалогов — в текущей вкладке.

Английские подписи находятся в файлах `en.ts` в каталогах `src/shell`, `src/overview`, `src/workspace` и `src/details`. Для подключения языка добавьте словари с такими же ключами и зарегистрируйте их в `catalogs` в `src/i18n.tsx`. Приложение выбирает поддерживаемый язык по настройкам браузера и использует английский по умолчанию. Даты, время и денежные значения выводятся через `Intl`.
