# Linea CRM

Desktop-фронтенд на React, TypeScript и Vite по [английскому макету Work overview в Figma](https://www.figma.com/design/d1MoOsOybR0sMmANvrpEnc/Linea-CRM?node-id=4-75).

## Локальный запуск

Понадобится Node.js 20.19+ из ветки 20 или версия от 22.12.

Команды ниже выполняются из папки `front/`. Из корня проекта сначала выполните `cd front`.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Начальный экран — Work overview. Для проверки типов и сборки выполните `npm run build`. Команда `npm run preview` запускает собранную версию.

## Данные и язык

Демонстрационный рабочий день — 4 ноября 2026 года. Интерфейс использует локальные записи CRM. Отметки выполнения задач сохраняются в этом браузере, история диалогов — в текущей вкладке. Ответы демо-ассистента подготовлены для примеров из макета.

Английские подписи находятся в файлах `en.ts` в каталогах `src/shell`, `src/overview`, `src/workspace` и `src/details`. Для подключения языка добавьте словари с такими же ключами и зарегистрируйте их в `catalogs` в `src/i18n.tsx`. Приложение выбирает поддерживаемый язык по настройкам браузера и использует английский по умолчанию. Даты, время и денежные значения выводятся через `Intl`.
